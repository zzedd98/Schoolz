# Intégration Massar

SchoolZ ne scrape pas Massar et ne suppose aucune API officielle. La première intégration sera limitée aux imports/exports CSV ou Excel dont les formats auront été obtenus et validés légalement auprès des établissements ou de sources officielles.

Toute future API officielle sera implémentée derrière `MassarAdapter`, avec versioning, audit, idempotence et tests contractuels. Aucun accès Massar n'existe au Milestone 0.
